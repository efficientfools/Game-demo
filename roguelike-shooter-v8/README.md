# Roguelike Shooter v6

Added:
- Weapon drops from enemies. They drop only the rounds currently loaded in the gun, with no spare magazines attached.
- Loose ammo pickups and magazine pickups.
- Medkit pickups. Press **H** to heal.
- Weapon swapping by picking up a dropped gun.

Run:
```bash
npm install
npm run dev
```

Build:
```bash
npm run build
```


v7 changes:
- Enemies have infinite reserve ammo.
- Added more enemy weapon variety: SMG, Assault Rifle, Sniper, LMG, Pistol.
- Assault Rifle and SMG behave as full-auto enemy weapons via short fire delays.

- Added random ground weapon spawns, including SMGs, assault rifles, and occasional LMGs.
